    The contract
    
          
    Three endpoints run the whole shop
    
          
    The frontend is plain HTML, CSS and JavaScript. The backend is three small serverless functions. They only ever talk through JSON.
    
        
    
      
    
      
    
        
    
          
    GET/api/products
    
          
    Loads the catalogue and the public pricing rules. Called when the page opens and when you switch category.
    
          
        
    
        
    
          
    POST/api/quote
    
          
    Receives product ids and quantities, looks up the real prices, and returns every line, saving, tax and the total.
    
          
        
    
        
    
          
    POST/api/checkout
    
          
    Prices the bag again on the server before confirming, so a tampered browser can never change what is charged.
